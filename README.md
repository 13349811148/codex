# 财务统计小工具 V1.2

基于 `Python + PySide6` 的 Windows 单机财务汇总工具。

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动

```bash
python main.py
```

## 当前已实现

- 主窗口和目录选择
- 配置持久化
- 文件扫描
- 文件名解析
- 来源识别
- 淘宝系 / 拼多多 支持 `CSV` 与 `XLSX/XLS`
- 金额标准化
- 分类映射
- 未匹配映射自动归类为 `暂未分类` 并弹窗提醒
- 大数据量后台处理与进度显示
- 异常信息支持复制选中 / 复制全部
- 按 月份/店铺/平台 汇总
- 导出 `总汇总表`

## 注意

- 当前版本内置淘宝系与拼多多已确认映射规则
- 未命中分类规则的记录会进入汇总表，分类显示为 `暂未分类`
