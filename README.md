# 财务统计小工具

基于 `Python + PySide6` 的 Windows 单机财务汇总工具骨架。

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动

```bash
python main.py
```

## 当前已实现

- 主窗口和目录选择
- 配置持久化
- 文件扫描
- 文件名解析
- 来源识别
- 拼多多 CSV 解析
- 淘宝 XLSX/XLS 解析
- 金额标准化
- 分类映射
- 按 月份/店铺/平台 汇总
- 导出 `总汇总表`

## 注意

- 当前版本只内置了已确认的淘宝和拼多多映射规则
- 未命中分类规则的记录会进入异常列表，不参与汇总
