# Proposal: Desktop Finance MVP

## Intent
为公司内部财务提供一个 `Windows` 单机桌面工具，用于从指定文件夹批量读取各店铺账务文件，按业务规则完成标准化、分类映射、汇总统计，并导出 `Excel` 报表。

## Problem
当前财务数据分散在多个平台导出的 `CSV/XLS/XLSX` 文件中，文件结构和字段格式不统一，人工汇总成本高，且容易出现口径偏差。

## Scope
- 支持从指定目录扫描 `CSV/XLS/XLSX`
- 支持 `拼多多` 与 `淘宝系` 两类来源模板
- 支持 `淘宝 / 天猫 / 淘工厂 / 淘农场 / 拼多多`
- 各平台账单同时支持 `CSV/XLS/XLSX`
- 从文件名识别 `平台` 与 `店铺名`
- 从明细时间提取 `月份`
- 按既定分类规则生成 `明细分类` 和 `大类`
- 未命中分类规则时归类为 `暂未分类`
- 导出后对未命中规则进行弹窗提醒
- 导出单个 `Excel` 文件，包含一个 `总汇总表`
- 运行前弹出保存对话框，由用户选择导出位置
- 处理大批量数据时保持界面可响应，并显示处理进度
- 异常与提醒信息支持复制

## Out of Scope
- 多用户与权限体系
- 云同步
- 自动提醒
- 去重逻辑
- 原始明细导出
- 规则管理界面

## Users
- 公司内部财务，单人使用

## Approach
- 使用 `Python + PySide6` 构建桌面应用
- 使用 `pandas` 处理异构账单与汇总
- 使用 `openpyxl` 导出 `Excel`
- 使用 `SQLite` 保存配置与运行日志
- 采用规则驱动的解析与分类策略，避免把平台口径硬编码到 UI 层

## Expected Outcome
用户选择数据目录后，点击 `一键生成报表`，系统自动完成导入、分类、汇总和导出，并在界面中展示进度、结果、异常和分类提醒。
